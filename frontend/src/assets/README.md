# Assets

Organise static files here.

- `images/` — hotel/room photos, hero backgrounds, partner logos.
- `fonts/` — self-hosted font files if you move off Google Fonts.
- `icons/` — brand/marketing SVGs (the app's runtime icon set lives in `src/components/ui/Icons.jsx`).

Import via the `@` alias, e.g. `import hero from "@/assets/images/hero.jpg"`.
